# 职业 CS2 赛事订阅

目标：在 QQ 群发送 `#今日比赛` 查看比赛 ID，发送 `#赛事订阅 比赛ID` 订阅；
比赛结束且最终比分齐全后，由单独的 QQ 账号向同群发送一条赛果。
`#我的赛事` 查看本人在本群的订阅，`#赛事取消 比赛ID` 仅取消本人的订阅。
同一群多人订阅同一场，只播报一次。程序每两分钟检查一次已订阅比赛。

## 赛事目录与赛果查询

赛事小号支持按年份、赛事、阶段和比赛浏览已收录的 CS／CS2 赛事。赛程数据以 PandaScore 实际建档为准；未建档的未来赛事不会预先显示。

- `#help` 或 `@赛事小号 help`：显示简短指令菜单。@时必须选中赛事小号。
- `#今日比赛`：北京时间正午 12 点至次日正午 12 点的 CS2 比赛，包含该窗口内已结束、进行中和未开始的比赛。比赛按开赛时间排列；发送 `#序号` 看详情。
- `#赛事 上海major 2024`：列出该赛事实际收录的阶段。发送 `#序号` 进入下一层，再选择比赛查看比分。
- `#赛事 上海major`：列出已收录的不同年份，用 `#序号` 选择。
- `#赛事 2024`：从该年目录浏览；目录较长时，可按序号选择“下一页”和“下一批年份赛事”。
- `#赛事 上海major 2024 冠军组`：直接列出该阶段比赛。常见别名包括“第一阶段／一阶段／揭幕赛／挑战者组”“第二阶段／二阶段／传奇组”“冠军组／淘汰赛”。名称以数据源实际分期为准。
- `#赛事 1079435`：直接按 PandaScore 比赛 ID 查询；也可直接发送 `#1079435`。
- `#近期赛事`（也可发送 `#近期大赛` 或 `#赛事 近期`）：列出当前进行中、或过去 72 小时内结束的 S／A级 CS2 大赛。按赛事合并不同阶段，发送 `#序号` 进入阶段目录。目录缓存五分钟。
- `#绑定链接 申请编号`：若官方机器人已记录待验证 Steam 绑定，由赛事小号回复远程验证链接；申请编号可从官方机器人的“我的绑定”取得。

除 `@赛事小号 help` 外，赛事小号指令都要以 `#` 开头；旧的无前缀指令不再响应。编号选择属于发送指令的群成员，各人在不同群中的选择互不影响；15 分钟后失效。比赛详情显示对阵、系列赛比分、状态、开赛时间、赛制和来源。免费数据源没有的逐图比分及选手数据不会编造。

现有 QQ 开放平台机器人继续负责完美 CS2 查询和绑定。
[腾讯官方文档](https://github.com/tencent-connect/bot-docs/blob/main/docs/develop/api-v2/server-inter/message/send-receive/send.md)
说明主动消息已停止提供；本项目实测主动发群消息得到 `40034105`。
职业赛事的自动发送端因此使用单独 QQ 账号与本机 NapCat OneBot 接口，
不复用官方机器人的 AppID 或 AppSecret。

## 已完成的本机接入设置

1. 准备单独 QQ 账号，并将其加入目标群。
2. 按 [NapCat 安装文档](https://napneko.github.io/guide/install)在运行本项目的电脑上安装并登录该账号。
   在 WebUI 中启用仅监听 `127.0.0.1` 的 OneBot HTTP 服务（默认端口 3000）和
   WebSocket 服务（默认端口 3001），为两者配置同一个随机访问令牌。
3. 在 [PandaScore](https://app.pandascore.co/signup)申请免费账号，于控制台取得 API 令牌。
   免费套餐提供赛程与最终比分；[逐场选手统计属于 Historical 套餐](https://developers.pandascore.co/docs/plan-reference)。
   如需争取免费的官方详细数据，可另行申请 [GRID Open Access](https://grid.gg/open-access/)；
   它需审核，比赛覆盖范围以获批权限为准。
4. 将令牌写入项目根目录 `.env`，不要发到 QQ 群或聊天中：

   ```text
   PANDASCORE_TOKEN=你的PandaScore令牌
   NAPCAT_ACCESS_TOKEN=你的NapCat本机令牌
   NAPCAT_HTTP_PORT=3000
   NAPCAT_WS_PORT=3001
   ```

启动：

```powershell
.\.venv\Scripts\python.exe -u -m qq_cs2_bot.esports_service
```

当前赛果包括赛事名称、双方最终大比分；地图与每位选手详细数据若来源未提供，
会明确显示“当前数据源未提供”。报告标注 PandaScore 来源。
大赛级别使用 PandaScore 的 tournament tier 字段；[PandaScore 对 S／A级的定义](https://developers.pandascore.co/docs/tournaments-in-depth)可供参考。
NapCat 登录、小号所属群读取、PandaScore 赛程查询和赛事目录查询已实测。真实完赛后的自动群播报仍待验证。
发送结果不明时任务会停在 `unknown` 状态，避免自动重试导致群里重复播报。
