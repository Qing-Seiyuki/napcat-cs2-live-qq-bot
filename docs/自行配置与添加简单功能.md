# 赛事 bot：自行配置与添加简单功能

适用于本项目当前的 NapCat 小号赛事服务。电脑 QQ 主号和原有官方机器人是另外的连接，不需要退出或修改。

## 1. 先分清文件用途

项目位置：你克隆本仓库后保存的本机目录。

| 文件 | 用途 | 什么时候修改 |
| --- | --- | --- |
| `.env` | 数据源令牌、NapCat 连接信息 | 更换令牌、修改端口 |
| `qq_cs2_bot/esports_commands.py` | 群指令识别、回复文字 | 新增帮助、固定回复、指令别名 |
| `qq_cs2_bot/esports_service.py` | 连接、接收群消息、定时检查订阅 | 修改服务行为 |
| `qq_cs2_bot/cs2_updates.py` | CS2 官方更新中文播报 | 修改公告整理规则 |
| `qq_cs2_bot/esports_result.py` | 赛后结果的展示文字 | 修改战报格式 |
| `data/esports.sqlite3` | 已保存的订阅与去重记录 | 不要用文本编辑器修改 |

**当前没有“填入功能名称就自动启用”的功能配置文件。** 在 `.env` 里自行添加 `帮助=...` 等字段不会生效。简单回复需要按下面的方法修改 Python 文件。

## 2. 修改连接配置

用记事本或代码编辑器打开项目根目录 `.env`，保留已有内容，只修改对应行，不要整份覆盖。

```dotenv
PANDASCORE_TOKEN=你的赛事数据令牌
NAPCAT_ACCESS_TOKEN=你的NapCat接口令牌
NAPCAT_HTTP_PORT=3000
NAPCAT_WS_PORT=3001
```

- 每项一行，使用英文等号；不要把上面的说明文字当作真实令牌填写。
- `NAPCAT_ACCESS_TOKEN` 是 OneBot 接口令牌，不是 QQ 密码，也不是 NapCat 管理页面密码。
- 两个端口必须与 NapCat 中的 HTTP、WebSocket 服务配置一致。
- 当前程序连接地址固定为 `127.0.0.1`，也就是本机。
- `.env` 修改后需要重启赛事服务。只改令牌内容但没有同步 NapCat，会导致连接失败。
- 令牌留在本机，不要把 `.env` 发到群里或上传到公开仓库。

NapCat 的连接配置可通过本机管理页 `http://127.0.0.1:6099/webui/` 查看。当前接口已经接通，没有需求时无需修改。

CS2 官方更新播报需要 AI 服务密钥：可用 OpenAI 的 `OPENAI_API_KEY`，或配置 `CS2_NEWS_AI_PROVIDER=deepseek` 和 `DEEPSEEK_API_KEY`。可选 `CS2_NEWS_AI_INTERPRET=1` 开启简短 AI 解读，具体见 [CS2 更新播报](CS2更新推送可行性.md)。

## 3. 修改帮助菜单与添加固定回复

帮助菜单已经内置。在 `qq_cs2_bot/esports_commands.py` 中修改 `HELP = (...)` 的文字即可；群里用 `#help` 或 `@机器人 help` 查看。不要改动 `#` 前缀规则。

若要新增 `#群规` 这样的固定回复，先备份 `qq_cs2_bot/esports_commands.py`，再在 `HELP = (...)` 后面加入：

```python
SIMPLE_REPLIES = {
    "群规": "友好交流，请勿刷屏。",
    "开黑时间": "今晚 20:00 开黑。",
}
```

找到 `command_reply` 中的这段识别代码：

```python
    is_recent = text in ("近期赛事", "近期大赛", "赛事 近期")
    is_browser = bool(parts) and (parts[0] == "赛事" or (len(parts) == 1 and parts[0].isdigit())) and not is_recent
    if not parts or (parts[0] not in ("今日比赛", "赛事订阅", "赛事取消", "我的赛事", "help") and not is_browser and not is_recent):
        return None
```

在 `if not parts ...` 前插入 `is_simple_reply = text in SIMPLE_REPLIES`，并在这条判断语句的末尾 `and not is_recent` 后追加 `and not is_simple_reply`。之后找到：

```python
    if not store.claim_event(app, group_id, str(message_id)):
        return None
```

紧接着插入：

```python
    if is_simple_reply:
        return SIMPLE_REPLIES[text]
```

保存并重启后，用 `#群规` 测试。回复按整条指令匹配，`#群规是什么` 不会触发。

## 4. 给现有指令添加别名（可选）

例如让 `#赛程` 等同于 `#今日比赛`。在 `command_reply` 的 `parts = text.split()` 下方插入：

```python
    aliases = {"赛程": "今日比赛", "订阅": "赛事订阅"}
    if parts:
        parts[0] = aliases.get(parts[0], parts[0])
```

别名只替换第一个词。`#订阅 1234567` 会按 `#赛事订阅 1234567` 处理；原来的指令仍可使用。所有新指令都要以 `#` 开头，数字选择使用 `#1`、`#2`。

## 5. 保存、检查与重启

代码和 `.env` 都在服务启动时读取；保存文件不会让正在运行的进程自动更新。

打开 PowerShell，先进入项目：

```powershell
Set-Location '你克隆本仓库后保存的本机目录'
```

先检查语法。没有输出且正常返回表示语法检查通过，但不代表功能测试已经通过：

```powershell
.\.venv\Scripts\python.exe -m py_compile qq_cs2_bot/esports_commands.py
```

如果出现 `SyntaxError` 或 `IndentationError`，根据提示行号检查引号、逗号和缩进，修好后再继续。

停止当前赛事服务：以下命令只选择名称为 Python、且启动参数明确包含赛事服务模块的进程，不会关闭 QQ。使用进程查询是为了避免依赖可能已经过期的 PID 文件。

```powershell
Get-CimInstance Win32_Process |
    Where-Object {
        $_.Name -match '^python(w)?\.exe$' -and
        $_.CommandLine -match '\bqq_cs2_bot\.esports_service\b'
    } |
    ForEach-Object { Stop-Process -Id $_.ProcessId }
```

随后启动服务，调试时建议让窗口保持可见：

```powershell
.\.venv\Scripts\python.exe -u -m qq_cs2_bot.esports_service
```

出现“赛事订阅服务已连接本机 NapCat。”后，在群里发送修改后的指令。运行过程中这个窗口会一直占用；按 `Ctrl+C` 可停止服务。不要同时开两个赛事服务实例。

如果只想调整订阅比赛的检查频率，可使用启动参数，例如每 180 秒检查一次：

```powershell
.\.venv\Scripts\python.exe -u -m qq_cs2_bot.esports_service --poll-seconds 180
```

默认 120 秒，允许 60～3600 秒。此参数影响赛后结果检查，不影响正常群指令的接收。

## 6. 出错时恢复

1. 若新服务正在运行，先按 `Ctrl+C` 停止。
2. 用备份内容恢复 `esports_commands.py`。
3. 再运行语法检查和启动命令。
4. 保留 `data/esports.sqlite3`，已有订阅和去重记录在其中，不需要删除。

此前后台启动的日志位于 `output/esports-service.log` 和 `output/esports-service-error.log`。按本教程在窗口中启动后，新的日志直接显示在窗口内。

## 7. 哪些功能还需要进一步开发

帮助菜单、固定回复、已有指令别名，可以按本教程添加。自动定时发公告、报名统计、按队伍持续订阅、AI 聊天、查询额外网站，都需要新的程序逻辑或数据源，不能只在 `.env` 中添加一行实现。

当前指令处理未设置群白名单，小号加入其他群后，这些指令也可能在那里触发。固定回复不要包含只适合某一个群公开的信息。

本教程提供修改示例，没有自动把这些示例启用到正在运行的服务中。
