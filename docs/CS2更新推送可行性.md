# CS2 游戏更新播报

2026-10-23 验证结果：可行。Valve 的 [Steamworks `ISteamNews/GetNewsForApp/v2` 文档](https://partner.steamgames.com/doc/webapi/ISteamNews)提供按 AppID 获取新闻的公开接口。CS2 的 AppID 是 730。本机对 `https://api.steampowered.com/ISteamNews/GetNewsForApp/v2/?appid=730&count=5&maxlength=500&feeds=steam_community_announcements` 的请求成功返回更新文章，包含文章 ID、标题、发布时间、正文摘要和链接；该公开接口没有要求提供 Steamworks 发布者密钥。

可实现的流程：

1. 每 5～10 分钟读取一次 AppID 730 的 `steam_community_announcements`；此筛选避免把第三方游戏媒体文章当成官方更新。
2. 依据文章 ID 去重，仅对新文章触发推送。初次启动先记录当前最新 ID，不补发历史文章。
3. 每个群单独设置开关，默认关闭；推送内容只包含标题、北京时间发布时间、一小段摘要和 Steam 链接。遇到多篇同时发布时合并或限速，避免刷屏。
4. 新闻接口失败时保持原去重记录，不发送不完整消息；NapCat 返回不明确时记录待核对状态，避免重复群发。

现已接入赛事小号服务。每 5 分钟检查一次 Steam 的 CS2 官方公告，只处理带 `patchnotes` 标记的更新，按文章 ID 去重。首次运行先建立基线，不补发旧文章；服务离线超过 48 小时也不补发过旧文章。每个 QQ 群默认关闭，群主或管理员用 `#更新播报 开`、`#更新播报 关` 切换，所有成员可用 `#更新播报 状态` 查看。群消息会含北京时间、中文更新要点和官方原文链接。

群主或管理员可用 `#播报解读 开／关` 和 `#播报原文 开／关` 分别控制自动播报是否显示 AI 简要解读和中文译文；`状态` 可供所有成员查看。`#更新播报 解读 开`、`#更新播报 原文 关` 等写法也支持。关闭中文译文、开启解读后，自动播报只发送简要解读。两项不能同时关闭。设置按群保存，不影响成员用 `#序号` 查询历史更新时的个人显示设置。未设过的群沿用本机 `CS2_NEWS_AI_INTERPRET` 作为解读默认值，中文译文默认显示。

历史查询：发送 `#更新历史` 查看最新 10 条；发送 `#更新历史 2` 查看第 2 页，后续页码同理，最多可查 20 页。列表按北京时间显示日期和序号；例如第 2 页的 `11` 可用 `#11` 查询。列表序号仅在当前群、当前查询人的最近一次列表中有效，保留 15 分钟；重新发送列表即可刷新。新的赛事目录会替换当前更新列表的序号，反之亦然。历史列表不调用 AI；首次查询某条未整理过的更新时，机器人先发送“正在查询，请稍后...”，再发送中文详情。已整理过的更新直接回复。历史查询无需开启群自动播报，但查询中文详情仍需要 API 密钥。

查看历史更新时，每位成员可发送 `#更新解读 开` 或 `#更新解读 关`，决定自己的 `#序号` 查询是否附带 AI 简要解读；`#更新解读 状态` 可查看当前状态。开关按群和成员保存，不影响其他人或自动播报。开关未设置时遵循本机 `CS2_NEWS_AI_INTERPRET` 默认值；有无解读的结果分别缓存，首次查询另一种版本仍可能需要稍等。

`#更新原文 开／关／状态` 控制是否显示 AI 翻译整理的中文更新要点（`#更新译文` 也可使用），这里的“原文”不是网页上的英文公告。发送 `#更新解读 开`、`#更新原文 关` 后，查询 `#序号` 只显示 AI 简要解读。若两个显示项都关闭，机器人会提示至少开启一项。此开关同样仅影响本人在当前群的历史查询。

中文整理需要 AI 服务的 API 密钥。默认使用 OpenAI；维护者可在本机 `.env` 配置：

```dotenv
OPENAI_API_KEY=你的OpenAI_API密钥
CS2_NEWS_AI_MODEL=gpt-5.6-luna
CS2_NEWS_AI_INTERPRET=0
```

若 OpenAI API 账户无法使用，可切换到 [DeepSeek 官方 API](https://api-docs.deepseek.com/zh-cn/)：先在其平台创建 API 密钥，再在 `.env` 添加以下三行。切换后旧的 `OPENAI_API_KEY` 和 `CS2_NEWS_AI_MODEL` 不再用于更新播报。

```dotenv
CS2_NEWS_AI_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的DeepSeek_API密钥
DEEPSEEK_MODEL=deepseek-flash
```

修改后重启赛事服务。AI 会把更新整理成逐条、简短的中文要点。`CS2_NEWS_AI_INTERPRET=1` 会在自动播报末尾附加简短的影响解读，并把推测明确标出；默认只整理更新，不解读。所选服务的密钥未配置时拒绝开启播报，整理失败时不会发送英文公告。各服务的 API 额度和收费由对应平台管理；内容很长时会压缩为中文要点，完整细节可点原文链接。

公开接口返回的是 Steam 新闻／公告，并非客户端补丁下载完成事件，因此不能保证与游戏文件上线时间完全同步。群消息发送结果不明确时记录为待核对状态，不自动重发，避免重复刷屏。
